# 好运世界杯 · 竞猜抽大奖

移动端 H5 活动页原型（纯静态，无需构建）。单页包含活动主题、2 场竞猜、九宫格抽奖。

## 功能说明

| 模块 | 说明 |
|------|------|
| 活动主题区 | 标题、积分规则说明、我的积分 / 已竞猜场次、规则与分享入口 |
| 竞猜赛事 | 固定 2 场（卡塔尔 vs 厄瓜多尔、英格兰 vs 伊朗），三选一投票 |
| 九宫格抽奖 | 外圈 8 奖品 + 中心抽奖按钮，跑马灯动效 |

## 积分规则

- 每场竞猜消耗 **100** 积分
- 猜对奖励 **300** 积分（需赛事 `result` 字段有值后自动结算）
- 九宫格每次消耗 **50** 积分
- 抽中「积分+20」额外回加 20 积分

## 验收清单

1. 打开页面即为活动主屏，无底部 Tab
2. 主题区显示积分、已猜场次；规则 / 分享可点
3. 恰好 2 场赛：未猜显示三按钮，猜后显示支持率进度条
4. 积分不足 100 时竞猜有提示
5. 九宫格可转、扣 50 分、显示中奖结果
6. 刷新后投票与积分仍在（`localStorage` key: `wc_lucky_cup_v1`）
