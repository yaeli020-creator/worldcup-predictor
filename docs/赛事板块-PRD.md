# 世界杯预言家 H5 · 赛事板块 PRD

> 基于原型：`worldcup-predictor.html`  
> 文档版本：v1.0  
> 适用范围：赛事板块（参与播报 + 赛事卡片轮播），不含个人信息区、专题 Banner、兑好礼

---

## 1. 背景与目标

### 1.1 背景

「世界杯预言家」是一款世界杯主题互动 H5，核心玩法是用户对单场赛事进行胜负/平局预测，猜对获得「南瓜值」奖励。赛事板块是页面的**核心转化区**，承载「发现赛事 → 参与竞猜 → 等待/查看结果」的完整路径。

### 1.2 产品目标

| 目标 | 说明 |
|------|------|
| 提升参与率 | 默认展示可竞猜场次，降低用户决策成本 |
| 营造氛围 | 实时播报增强社交感与紧迫感 |
| 状态清晰 | 6 种赛事状态，用户一眼看懂「能做什么」 |
| 引导留存 | 参与成功后弹窗引导开启 App 通知 |

### 1.3 成功指标（建议）

- 赛事卡片曝光率 ≥ 95%
- 赛事卡片 → 点击选项转化率 ≥ 15%
- 单场竞猜完成率（选选项并成功提交）≥ 90%
- 参与成功弹窗「打开 App 通知」点击率 ≥ 8%

## 4. 模块一：参与播报跑马灯

### 4.1 功能描述

页面顶部滚动展示其他用户的参与动态，营造活动热度。

### 4.2 展示规则

- 位置：赛事轮播上方，高度 40px
- 内容格式：`[头像] [昵称脱敏] [动作] [高亮信息]`
- 示例：`😎 球迷达*** 猜中 +300 南瓜值`
- 动画：水平无缝循环滚动，周期约 24s
- 交互：用户触摸/悬停时**暂停滚动**，松手后继续

### 4.3 播报类型

| 类型 | 动作文案 | 高亮示例 |
|------|----------|----------|
| 猜中 | 猜中 | +300 南瓜值 |
| 参与 | 参与了 | C组竞猜 |
| 冷门猜中 | 猜中冷门 | +100 南瓜值 |
| 兑换 | 兑换了 | 球迷T恤 |

### 4.4 数据要求

- 昵称脱敏：保留前 2～3 字 + `***`
- 数据源：服务端实时 feed 或轮询接口；原型为静态 Mock
- 列表长度：建议 ≥ 8 条，前端复制一份实现无缝循环

## 5. 模块二：赛事卡片轮播

### 5.1 功能描述

以横向卡片轮播形式展示多场赛事，用户可左右滑动切换，对当前场次进行三选一竞猜。

### 5.2 轮播交互

| 规则 | 说明 |
|------|------|
| 默认焦点 | 首张为**当前可竞猜且未参与**的场次（原型默认 index=0，阿根廷 vs 沙特） |
| 露出策略 | 当前卡片占宽约 `100% - 52px`，左侧露出下一张卡片边缘（peek 态） |
| 非当前卡片 | 透明度 60%、缩放 96%，提示可滑动 |
| 滑动方向 | 向右滑 → 看下一张（左侧隐藏的卡）；向左滑 → 返回上一张 |
| 切换阈值 | 水平位移 > 40px 触发翻页，否则回弹 |
| 跟手效果 | 拖动过程中轨道实时跟随手指/鼠标 |
| 边界 | 首张/末张不可越界 |

### 5.3 卡片结构（自上而下）

```
┌──────────────────────────────────┐
│ 竞猜截止：今天 18:00              │  ← 截止条
├──────────────────────────────────┤
│   🇦🇷        VS        🇸🇦        │  ← 对阵区
│  阿根廷              沙特          │
├──────────────────────────────────┤
│ [阿根廷]  [平局]  [沙特]          │  ← 三选一选项
│  68%用户选 12%用户选 20%用户选    │
├──────────────────────────────────┤
│ ⏳ 参与成功，待开奖               │  ← 参与状态条（已参与时）
│ 你选择了「沙特」，猜对开奖后...    │
├──────────────────────────────────┤
│ 您未参与本场竞猜                  │  ← 未参与提示（截止/开奖后）
└──────────────────────────────────┘
```

## 6. 赛事状态机

### 6.1 赛事状态（`status`）

| 状态值 | 含义 | 截止条文案 | 可否竞猜 |
|--------|------|------------|----------|
| `open` | 竞猜开放中 | 竞猜截止：{deadline} | 未参与时可 |
| `locked` | 已锁盘，待开赛 | 竞猜截止：已截止 | 否 |
| `ended` | 已开奖 | 竞猜已截止：{deadline} | 否 |

### 6.2 六种 UI 状态组合

| # | 赛事状态 | 用户参与 | 对阵示例 | 说明 |
|---|----------|----------|----------|------|
| 1 | open | 未参与 | 阿根廷 vs 沙特 | 三按钮可点，实心色 |
| 2 | open | 已参与 | 卡塔尔 vs 厄瓜多尔 | 已选高亮 + 待开奖状态条 |
| 3 | locked | 未参与 | 德国 vs 日本 | 选项已揭示 + 未参与提示 |
| 4 | ended | 未参与（平局） | 比利时 vs 加拿大 | 中间显示「平局」+ 未参与提示 |
| 5 | ended | 已参与·未猜中 | 巴西 vs 塞尔维亚 | 胜方高亮 + 未猜中状态条 |
| 6 | ended | 已参与·猜中 | 葡萄牙 vs 加纳 | 胜方「赢」角标 + 猜中状态条 |

> 详细 UI 对照见：[赛事板块-6种状态UI对照.md](./赛事板块-6种状态UI对照.md)

### 6.3 状态流转

```
open ──(到达锁盘时间)──> locked ──(公布赛果)──> ended
open ──(直接截止开奖)────────────────────────> ended

open + 未参与 ──(用户选择选项)──> open + 已参与
```

## 7. 选项区详细规则

### 7.1 选项定义

每场赛事固定 **3 个选项**：

| Key | 展示名 | 按钮色 |
|-----|--------|--------|
| A | 主队名称（teamA.n） | 深青绿 `#0A7A85` |
| D | 平局 | 主色青绿 `#00C9A7` |
| B | 客队名称（teamB.n） | 暖橙红 `#FF7043` |

> 淘汰赛若不支持平局，后端不下发 D 选项，前端隐藏平局按钮。

### 7.2 未参与态（可竞猜）

- 按钮文案：`{队名}` + 次行 `{pct}%用户选`
- 点击任一选项 → 提交竞猜 → 刷新卡片 → 弹出「参与成功」弹窗
- **不可撤销、不可修改**

### 7.3 已参与 / 已截止 / 已开奖态

- 按钮变为非交互元素
- 用户所选选项：实心高亮 + 「已选」标签
- 未选选项：浅色描边「revealed」态
- 下方始终展示各选项的支持率百分比

### 7.4 已开奖对阵区

- 胜方：国旗边框高亮 + 右上角「赢」角标
- 负方：透明度 45%
- 平局：中间显示「平局」文案，非 VS
- 可选展示比分（`score` 字段，如 `3:2`）

## 10. 数据模型

### 10.1 赛事对象 `Match`

```json
{
  "id": "m3",
  "status": "open",
  "question": "世界杯小组赛C组，哪支球队会获胜？",
  "deadline": "今天 18:00",
  "teamA": { "f": "🇦🇷", "n": "阿根廷" },
  "teamB": { "f": "🇸🇦", "n": "沙特" },
  "pcts": { "A": 68, "D": 12, "B": 20 },

  "result": null,
  "score": null
```

```json
{ "m1": { "pick": "B" } }
```

## 11. 接口需求（正式版）

| 接口 | 方法 | 说明 |
|------|------|------|
| `GET /matches` | GET | 获取赛事列表（含状态、支持率、用户是否已参与） |
| `POST /matches/{id}/vote` | POST | 提交竞猜，`body: { pick: "A" }` |
| `GET /feeds` | GET | 获取参与播报列表 |
| `GET /user/votes` | GET | 获取用户历史竞猜 |

### 列表排序建议

1. `open` 且用户未参与 → 最前
2. `open` 且用户已参与
3. `locked`
4. `ended`（按时间倒序）

## 12. 异常与边界

| 场景 | 处理方式 |
|------|----------|
| 未登录点击选项 | 跳转/唤起登录，不提交 |
| 网络失败 | Toast「提交失败，请重试」，不更新本地状态 |
| 并发提交 | 服务端幂等，返回已参与状态 |
| 滑动与纵向滚动冲突 | 水平位移 > 垂直位移且 > 6px 才接管横向滑动 |
| 仅 1 场赛事 | 隐藏 peek，禁用滑动 |
| 赛事中途下架 | 卡片置灰 + 「赛事已取消」 |

## 14. 验收标准

- [ ] 播报气泡连续滚动，首尾无缝衔接
- [ ] 默认展示可竞猜场次，左侧露出下一张
- [ ] 左右滑动切换流畅，未达 40px 回弹
- [ ] 6 种 UI 状态展示与原型一致（见 UI 对照文档）
- [ ] 点击选项后弹出参与成功弹窗，已参与不可修改
- [ ] 未登录用户点击选项触发登录（正式版）

## 15. 待产品确认项

1. 奖励规则：参与即得 50 南瓜 vs 猜对才得；是否展示赔率 `mults`？
2. 登录拦截：原型未登录也可投票，正式版是否强制登录？
3. 竞猜消耗：是否消耗南瓜值参与？
4. 题目展示：`question` 字段是否在卡片中展示？
5. 比分展示：`ended` 状态是否在 VS 区展示 `score`？
6. 冷门加成：Toast 预留了「冷门加成 ×2」，赛事板块是否需展示？
